<h1>📚 BIBLIOTECA API</h1>
<p>Aplicación desarrollada en Java que permite consultar, visualizar y gestionar una biblioteca de libros consumiendo una API externa. Incluye funcionalidades como búsqueda en tiempo real, sistema de favoritos y persistencia de datos.</p>

<h2>🚀 FUNCIONALIDADES</h2>

    🔍 Búsqueda de libros en tiempo real.
    ⭐ Añadir libros de favoritos.
    💾 Exportar e importar favoritos desde archivo.
    📖  Exportar e importar favoritos desde archivo.
    
<h2> 🛠️ TECNOLOGIAS UTILIZADAS</h2>

    JavaFX
    Funciones Lambdas
    Ficheros (BufferedReader / BufferedWriter)
    API REST (consumo de datos)
    Mave
